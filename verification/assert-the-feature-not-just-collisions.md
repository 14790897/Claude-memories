# 碰撞检测测不出「该挖的洞没挖」

**结构件的「验证通过」，必须逐特征断言，不能只跑干涉检查。**

## 为什么

做 3D 打印外壳时连续翻车三次，每次都「跑过验证」了：

1. **磁铁窝切在内腔的空气里**——前框背面四个位置通空，磁铁装不上
2. **前后盖根本没有闭合结构**——默认「磁铁会吸住」，实物到手才发现没有卡扣
3. **PCB 顶边有两个定位缺口**，没解析板子外轮廓，做出来的内腔是纯矩形，缺口裸露在画面区

三次跑的都是「元件 vs 外壳干涉、单壳体、体积」这三项——**一个都查不出上面这些问题**。

## 出图前的六道闸

1. **输入解析** — 板子用 Gerber 轮廓层的真实多边形，不能只取包围盒；元件用实体模型
2. **特征存在性** — 每个减材特征生成后沿轴线打射线：窝必须停在预期深度（穿过去 = 切在空气里）、孔必须完全贯穿、筋必须命中实体
3. **配合验证** — 磁铁对磁铁、定位筋对板缺口、插舌对插槽，逐对算咬合深度
4. **干涉** — 元件 vs 外壳（就是常规那一项）
5. **闭合方式** — 前后盖之间必须存在经过验证的机械连接，不能默认某种方式会成立
6. **制造** — 单壳体、水密、体积、工艺门槛

## 参数级可行性也要先算

墙厚 3.45mm 挖 3.2 深的窝只剩 0.25mm，低于最小壁厚——**应该在这里直接 FAIL，而不是先画了再说。**

## 两条纪律

**每版必须看三张图**（俯视、剖视、爆炸），而且剖切要**按功能位定点切**（每个角、每个开口），不是随便切一刀。

**数字验证不了的项要明确标注「未验证，需实物」**——卡扣力度、磁铁吸力、装配手感，不能笼统报「通过」。
