# 找 skill 必须联网搜

**被问「有没有某个 skill」时，要联网搜索，不能只翻本地目录就回答「没有」。**

## 为什么

被问到「有没有模拟人类说话的 skill」时，我只 `ls` 了本地技能目录和当前仓库，就下了结论。但那只能证明**本地没装**，不能证明**不存在**。

联网搜之后发现：同类 skill 在 GitHub 上有一批，其中最大的一个 7 万多星、MIT 协议、三天前还在更新。

## 怎么用

**判定「有没有」之前，先搜：**

- 技能市场与目录站
- GitHub（用搜索 API 比网页搜索准，按 star 排序）
- 官方仓库与社区合集

**结论要分清两种：**

| 说法 | 成立的前提 |
|---|---|
| 「本地没装，我给你装上」 | 搜到了 |
| 「搜遍全网都没有」 | 真的搜过了 |
| 「没有」 | ← 单独说不成立 |

**搜完给可安装的具体来源**——仓库地址、安装命令，不要只报一个名字。

## 一条附加经验

GitHub 的仓库搜索 API 对中文关键词支持不错，直接查比走搜索引擎更准：

```bash
gh api -X GET search/repositories -f q="<关键词>" -f per_page=10 \
  --jq '.items[]? | "\(.stargazers_count)\t\(.full_name)\t\(.description)"'
```

注意看 `pushed_at` 和 license——星数高但三年没动的仓库，装上去大概率跑不起来。
