# 用完就清，别等对方发现

**任务或管线跑完之后，自动清理自己产生的临时目录和大体积中间文件。**

## 为什么

一次收尾时发现某个工作目录累积到了 26 GB——视频暂存、实验中间产物、临时修复目录，都是历次任务留下的。用户的原话是「你这个用好之后要自动清理目录的」，而当时系统盘本来就紧张。

## 怎么用

**手工任务**：结束时删掉本次创建的临时目录和文件，尤其是 mp4 / wav / m4a 这类大文件。需要留档的放到明确的存档目录，并在总结里说一句「留了什么、在哪」。

**长跑的管线**：内置按年龄清理，而不是靠人记。一个可用的参数化写法：

- 临时目录超过 7 天自动删
- 大媒体文件超过 1 天自动删
- 用**白名单**保护真正的项目目录

## 一个反例

不要为了省事直接 `rm -rf work/`。工作目录里往往混着脚本、项目副本和正在用的东西，一刀切会删掉不该删的。正确做法是「白名单 + 年龄」，让清理规则可预测、可审查。
