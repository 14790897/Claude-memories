# 自动化打开的窗口移出屏幕

**做浏览器或桌面验证时，自己打开的窗口要移出用户视线。**

## 为什么

用户明确要求：「所有界面移到屏幕外」。他不是嫌吵——是不想让自动化开出来的窗口挡住自己正在做的事。

自动化窗口停留几秒到几分钟，但用户不知道它什么时候会消失、会不会抢焦点。**看不见 = 不用提防。**

## 怎么用

**开完就移走。** 把窗口移到负坐标（屏幕外），窗口本身还在、状态保留，需要时能移回来或直接关掉。

**只动自己开的。** 用户原有的窗口一个都不碰——不移、不缩放、不关闭。

**移不动的要说明。** 有些界面是宿主应用的一部分（比如集成在 IDE 里的预览面板），没法单独移动。这种情况直接讲清楚，让用户自己决定收起还是留着。

**用完可以移回或关闭。** 但别顺手把用户的窗口也一起收拾了。
