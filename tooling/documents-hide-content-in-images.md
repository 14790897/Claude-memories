# 文档的内容可能在图片里

**只提取到文字，不等于读全了文档。**

## 为什么

读一份 `.docx` 时只解析了文本节点，得出「第五节只有标题、正文为空」的结论，还写进了给对方的确认单。

对方提醒「那个是截图」——解出 `word/media/image1.png` 后确认：**那一节的正文就是一张截图**，内容完整。

这是一次**误报**，而且报到了别人面前。

## 怎么用

**读 docx 时，除了解析 XML 文字，还要列出并查看嵌入的图片：**

```python
[n for n in zipfile.ZipFile(p).namelist() if n.startswith("word/media/")]
```

**「标题后面紧跟下一个标题」不要直接判定为「内容缺失」**——先查那一段里有没有 `w:drawing` / `w:pict` 节点。

## 同样适用于

- **PDF**：扫描页、图表里的说明、文本框
- **网页**：CSS 背景图里的文字、canvas 渲染的内容
- **PPT**：备注、组合形状里的文本

## 判断标准

「我读到的是空白」有三种可能：

1. 真的是空的
2. 内容在图片里
3. 内容在结构上存在但解析器没走那条路

**在说出「这里缺内容」之前，要能排除后两种。** 因为这句话会反过来质疑对方的交付质量。
