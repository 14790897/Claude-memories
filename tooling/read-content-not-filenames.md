# 按笔记删视频，要读正文不要看文件名

**批量删除媒体文件时，匹配依据必须是文件内容，不是文件名里那个可能是随手起的编号。**

## 为什么

一次按笔记清理已看过的剧集。我解析文件名里的「第 N 集」去匹配，结果 129 个带集号的笔记只匹配上 8 个库内视频，删得严重不全。

原因：笔记很多没有编号——153 篇里有 23 篇完全无编号，集数、日期、标题常常只出现在正文里。文件名只是随手起的标题。

## 怎么用

**逐篇读完整正文**，不是只看 front matter、不是只看文件名。

**从正文里提取三类线索**：

- `第 N 集` / `第 N 期` 这类编号
- `YYYY-MM-DD` 这类日期
- 集标题里的关键词

**用线索去匹配媒体库条目**（集号字段、名称里的日期与标题），必要时做标题模糊匹配。

**删除前列出命中清单**（集号 + 标题），确认后再删。删完刷新媒体库、核对剩余集数。

## 推广

任何「按 A 去操作 B」的批量任务，先问一句：**A 里的标识符，是不是 B 的权威主键？**

文件名、目录名、标签、标题——这些都是人随手写的，不是系统 ID。真正的稳定标识通常藏在内容里，或者在数据库的某个字段上。
