# 上传到 Release 的文件名会被改写

**空格会变成点号。如果你的自动更新配置按原名找文件，就会 404。**

## 为什么

本地构建产物叫 `X Desktop Setup 0.31.0.exe`，通过 API 上传到 Release 后，资产名变成 `X.Desktop.Setup.0.31.0.exe`。

平时无所谓。接了自动更新就出事：更新配置里记的下载路径是**本地原名**（带空格），拼出来的 URL 在 Release 上不存在。

## 怎么用

给受影响的构建目标显式指定产物名，让三处完全一致：

1. 本地构建出来的文件名
2. Release 上的资产名
3. 更新清单里记的路径

```yaml
artifactName: "X.Desktop.Setup.${version}.${ext}"
```

**改产物命名前**，先 grep 一遍文档、下载页、安装脚本里引用的文件名——它们可能写着带空格的旧名字。

## 一条推论

**文件名是接口。** 一旦有别的系统按名字来找它，它就不再是随便起的了。
